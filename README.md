# voy_web

Frontend Angular del sistema **VOY** (parqueaderos de bicicletas).

Stack: **Angular 22** · **Tailwind CSS v4** · tema **Emerald** · consume `voy_api`.

## Requisitos

- Node.js LTS 22+
- API `voy_api` en `http://127.0.0.1:8000` (a partir de la Fase 1 del plan)

## Desarrollo

```bash
npm install
npm start
```

Abre `http://localhost:4200`.

## Notas

- Fase 0: scaffold + tokens Emerald (sin conexión API aún).
- No hay seeds de datos en este repo.
